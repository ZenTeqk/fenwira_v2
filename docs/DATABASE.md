# Database

## Scope

Every entity for phases 3–11: the columns, types, constraints and indexes, the phase that introduces each one, and whether it is tenant-owned. This document is the source of truth for the Prisma schema (`packages/database/prisma/schema.prisma`). A schema change updates this doc in the same PR.

## Conventions

| Rule | Value |
| --- | --- |
| Engine | PostgreSQL 16. Extensions: `citext`, `pg_trgm`. |
| Table names | `snake_case`, plural (Prisma `@@map`) |
| Column names | `snake_case` (Prisma `@map`). Prisma fields are camelCase. |
| Primary key | `id uuid` (UUIDv7, generated by the app: `@default(uuid(7))`) |
| Timestamps | `created_at timestamptz NOT NULL DEFAULT now()`, `updated_at timestamptz NOT NULL` (`@updatedAt`), all UTC |
| Soft delete | `deleted_at timestamptz NULL` only where marked **SD**. Unique indexes on SD tables are partial (`WHERE deleted_at IS NULL`). |
| Tenant column | `tenant_id uuid NOT NULL` → `tenants(id) ON DELETE CASCADE`, marked **T** (standard RLS policy). |
| Enums | Postgres enums, `UPPER_SNAKE` values |
| Money | `bigint` minor units + `currency char(3)` (ISO 4217). Never float. |
| Phone | `phone_e164 text` (E.164, validated in the app) |
| JSON | `jsonb`, always validated by a Zod schema in `packages/contracts` before write |
| Secrets | `bytea` ciphertext produced by `packages/config/crypto` (see `SECURITY.md`) |
| FK indexes | Every FK column is indexed. Tenant-owned list queries use composite indexes that lead with `tenant_id`. |

Legend: **T** tenant-owned (RLS) · **G** global · **SD** soft delete · **AO** append-only (UPDATE/DELETE revoked) · *P#* phase introduced

## Retention

| Data | Retention | Mechanism |
| --- | --- | --- |
| `webhook_events` | 30 days | `system.purge_expired` |
| `outbox_events` DISPATCHED | 7 days | `system.purge_expired` |
| `idempotency_keys` | 24 hours | `system.purge_expired` |
| `webhook_deliveries` | 30 days | `system.purge_expired` |
| `analytics_events` | Per `analytics_retention` entitlement | Maintenance job |
| `audit_logs` | ≥ 1 year | Never auto-purged in v2 |
| Messages, contacts | Until the tenant or the contact is deleted | Tenant deletion → cascade |
| Import/export files | 7 days | MinIO lifecycle + `files` cleanup |
