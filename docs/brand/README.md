# Fenwira brand assets

The originals are in `images/` at the repository root. Web derivatives are generated by `python3 scripts/brand-assets.py` (Pillow and numpy; a manual tool, not part of CI). Re-run it after replacing an original, and never edit a derivative by hand.

| Original (`images/`)                         | Derivative                                                                                                  | Used for                                                                                                                                                                                                                        |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Fenwira_symbol_emerald.png` (transparent F) | `apps/web/public/brand/fenwira-mark.png`                                                                    | Sidebar: the symbol with the live "Fenwira" wordmark, or the symbol alone when the sidebar is collapsed                                                                                                                         |
| `Fenwira_favicon_light.png`                  | `public/brand/favicon-light.png`, `apps/web/app/favicon.ico`                                                | Browser favicon for light colour schemes (`/favicon.ico` for legacy requests)                                                                                                                                                   |
| `Fenwira_Favicon_dark.png`                   | `public/brand/favicon-dark.png`                                                                             | Browser favicon for dark colour schemes                                                                                                                                                                                         |
| `Fenwira_App_Icon.png`                       | `public/brand/apple-icon.png` (180), `app-icon-192.png`, `app-icon-512.png`                                 | iOS home screen and the web app manifest (`app/manifest.ts`). Cropped full-bleed so platform masks never show the white margin.                                                                                                 |

It is uploaded in Meta's WhatsApp Manager; Fenwira doesn't set it.                                                                                       |

Rules:

- The logo's gradient lives only in these images. UI colours stay the design-system tokens (`docs/design/FENWIRA_DESIGN_SYSTEM.md`): the logo is not a source of new UI colours.
- Use the lockups as supplied, at least 120 px wide, with clear space of at least the height of the "F" crossbar.
- Always give the image text: `alt="Fenwira by ZenteqK"` for lockups, `alt="Fenwira"` for the symbol alone, and `alt=""` when the name is already written next to it.

## Third-party logos

Official marks of integrations Fenwira supports live in `apps/web/public/integrations/` and are rendered only through `IntegrationLogo` (`apps/web/components/integrations/integration-logo.tsx`). They were downloaded unmodified on 8 October 2026:

| File                | Mark                              | Source                                                                                                                                                                            |
| ------------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `whatsapp.svg`      | WhatsApp logo                     | Wikimedia Commons reproduction of the WhatsApp brand mark (`commons/6/6b/WhatsApp.svg`); replace with the file from WhatsApp's brand resources (whatsappbrand.com) when available |
| `erpnext.svg`       | ERPNext logo                      | Frappe's ERPNext repository (`erpnext/public/images/erpnext-logo.svg`)                                                                                                            |
| `google-sheets.png` | Google Sheets product icon (2020) | Google's branding CDN (`gstatic.com/images/branding/product/2x/sheets_2020q4_48dp.png`)                                                                                           |
| `zoho.png`          | Zoho corporate logo               | Zoho's static site (`zohowebstatic.com/.../zoho-logo-512.png`)                                                                                                                    |
| `shopify.svg`       | Shopify bag logo, full colour     | Shopify's brand assets CDN (`cdn.shopify.com/.../shopify-logo-shopping-bag-full-color-*.svg`)                                                                                     |

Rules:

- Use a mark only for an integration Fenwira actually supports, next to its name, to say "works with". Never for unsupported integrations or to imply endorsement.
- Never recolour, redraw, crop, stretch or animate a mark. Show it on a white tile with its own clear space. Its colours are part of the artwork and never become UI colours.
- The SVGs were checked for scripts and external references before they were added. Re-check any replacement.
- Status (connected, failing) is always shown by `StatusBadge` or the status dot, never by the logo.
